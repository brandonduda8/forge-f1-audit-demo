Check your website for common accessibility problems

A quick automated scan that flags common accessibility problems on your homepage: images without alt text, form fields without labels, skipped heading levels, a missing page language and low-contrast text. It is a starting point, not a legal audit.

Only check websites you own or are allowed to check. The free check makes three read-only requests to the site (the homepage, robots.txt and sitemap.xml) and public DNS lookups for your SPF and DMARC email records.

What it checks

  • Image alt text — images with no alt attribute. An empty alt="" counts as decorative, which is correct for decoration; hidden images are skipped.
  • Form field labels — fields with no label, aria-label, aria-labelledby or title, so a screen reader can't say what to type.
  • Heading order — headings that jump more than one level (an h2 followed by an h4).
  • Page language — a lang attribute on the page, so screen readers pronounce it correctly.
  • Text contrast — the WCAG contrast ratio, but only where an element sets both its text and background colour inline. Colours set in stylesheets need a browser render, so then contrast is listed as not measured.

The free check shows the top accessibility problem it found. The full report lists every one, with a fix and an effort estimate, and gives accessibility its own score, separate from the grade. The Pro Checkup also checks image alt text and page language on up to 4 more of your pages.

What it is not

This is not a legal accessibility audit, and it can't tell you whether your site complies with the ADA, WCAG or any other law or standard. Automated checks catch only some accessibility problems.

  • It doesn't test with a screen reader or a keyboard.
  • It doesn't read colours from stylesheets, check focus order, captions, or how the page behaves when zoomed.
  • It checks the homepage (plus up to 4 pages with Pro), not every page.

For a full review, a person needs to test the site with assistive technology.

Questions

Will this make my site ADA compliant?
No. It flags common problems that are easy to fix, which helps, but it isn't a compliance audit and can't certify anything.
Why does it say contrast was not measured?
Most sites set colours in stylesheets. Working out the real colours needs a full browser, which the checker doesn't run, so it says not measured instead of guessing.
Is an empty alt attribute a problem?
No. alt="" tells screen readers an image is decoration, which is correct for decorative images. Only images with no alt attribute at all are flagged.
Does it change my site?
No. It reads your public homepage like a visitor's browser would and never changes anything.
